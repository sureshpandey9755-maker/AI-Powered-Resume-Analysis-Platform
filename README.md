# AI-Powered Resume Analysis Platform

An intelligent candidate resume analysis system built with FastAPI backend, Streamlit interactive dashboard, and SQLite database.

## 🚀 Features
- **Resume Text Extraction:** Extracts candidate data from PDF/DOCX formats.
- **Skill & Experience Mapping:** Categorizes technical skills and estimates professional experience.
- **REST API Integration:** Process resumes seamlessly via FastAPI backend endpoints.
- **Interactive UI:** Built using Streamlit for clean data visualization.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python, SQLite
- **Frontend:** Streamlit, Pandas
- **Analytics:** Custom Machine Learning Logic & LaTeX Formulae
